# CoffeeHeart — Chris Cui

A dark, desktop-first portfolio for software engineer Chris Cui, built with React and Vite.

## Run locally

```bash
pnpm install
pnpm dev
```

Create a production build with `pnpm build`.

## Site structure

- Full-screen video hero
- Profile, contact details, project data, and personal timeline
- Large selected-work cards for YumTrip, Market Signals, and CoffeeHeart
- Expertise cards spanning product, systems, interface engineering, and applied AI
- Full-screen contact close

The hero motion footage is from Mixkit and is used under the Mixkit Free License. The poster and social preview artwork were generated specifically for this project.
